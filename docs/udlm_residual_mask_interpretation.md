# Interpreting residual MASK tokens in the prospective V12 comparison

This read-only audit uses source `be18a3244a717978e027d6e43ba0ac20b8137e4a`.
It identifies no blocking sampler/configuration mismatch. It is a mathematical
and CPU implementation check, **not molecular evidence or a model improvement**.
The proposed V12 settings retain 128 predictor steps, temperatures 1 and 0.5,
top-p 1, no Gibbs correction, and a positive inference endpoint.

## The ideal endpoint retains approximately nine MASK tokens per million positions

Let \(x_0\) be a clean content token, \(m\) the MASK token ID, \(z_s\) its noisy
state at time \(s\), \(\pi\) the stationary categorical distribution, and
\(\nu=0.001\) the configured `noise_eps`. The forward retention probability is
\(\alpha(s)=1-(1-\nu)s\). Thus, for clean content with \(x_0\ne m\),

\[
q(z_s=m\mid x_0)=(1-\alpha(s))\pi_m=(1-\nu)s\pi_m.
\]

For the MASK-rich mixture, \(\lambda=0.9\) is the MASK mixture weight,
\(w=0.0002\) is the empirical prior's uniform smoothing weight, and \(V=1880\)
is its active alphabet size. MASK has zero count in the pinned frequency
artifact, so its base mass is \(w/V\), and
\(\pi_m=\lambda+(1-\lambda)w/V\approx0.9000000106382978\).
At the inference endpoint \(s=10^{-5}\), the ideal probability is
\(8.991000106276596\times10^{-6}\), or 0.0008991%. Over \(N\) clean content
positions the expected count under this forward law is \(N\) times that
probability; for 10,000 positions it is approximately 0.08991. This expectation
does not require independence between positions.

[The sampler](../src/genmol/sampler.py) fixes editable positions from the original
input MASKs, draws their initial states from \(\pi\), then traverses a float32
`linspace(1, inference_eps, 129)`. The represented endpoint is
`9.999999747378752e-06`; the final model evaluation occurs at
`0.007822421379387379`. There is no extra clean-token draw at zero, rejection of
final MASKs, or forced replacement. A MASK can remain or be generated by a reverse
transition. Float32 grid/algebra rounding and float64 prior normalization cause
small numerical differences from the exact decimal formula.

## CE conversion and temperature act before the reverse bridge

For a selected position \(\ell\), let \(k=z_{t,\ell}\) be its observed token at
the current time \(t\), and let \(j\) index possible clean tokens. Define
\(D_j\) as the denoiser's normalized clean-token prediction at this position
given the full noisy sequence \(z_t\), and

\[
L_j=\alpha(t)\mathbf 1[j=k]+(1-\alpha(t))\pi_k.
\]

Here \(\mathbf 1\) is the indicator function. Full support and \(t>0\) ensure
\(L_j>0\). [CE conversion](../src/genmol/denoiser.py) subtracts \(\log L_j\)
from the network logit, so the normalized raw leave-one-out prediction is
\(R_j\propto D_j/L_j\). With temperature \(T>0\) and top-p 1,
[the bridge implementation](../src/genmol/diffusion.py) instead receives

\[
R_{T,j}\propto(D_j/L_j)^{1/T}.
\]

The corresponding implied clean weights, obtained by multiplying by the same
local likelihood, are
\(D_{T,j}\propto R_{T,j}L_j
=D_j^{1/T}L_j^{1-1/T}\), with each proportionality normalized over \(j\).
At \(T=1\), these weights equal \(D\). At \(T=0.5\), they are proportional to
\(D_j^2/L_j\), rather than merely squared clean probabilities. The secondary
temperature setting deliberately changes the reverse law.

With an exact denoiser and \(T=1\), this conversion yields the exact coordinate
reverse marginal. Multiplying coordinate marginals generally approximates the
correlated sequence reverse joint; 128 finite steps do not remove that issue.
The learned denoiser can assign positive clean MASK probability: the common
all-special training mask excludes special-token **targets and corruption of
framing**, while `exclude_special_tokens=false` leaves the corruption and output
alphabet full. There is no hard zero on MASK logits. Consequently, nine ppm is
an ideal forward reference, not a forecast or acceptance bound for either V12 arm.

There is also an initial-distribution approximation: \(\alpha(1)=\nu>0\), while
the sampler starts from independent \(\pi\) draws. For clean non-MASK content,
\(q(z_1=m\mid x_0)=(1-\nu)\pi_m\), whereas the initializer uses \(\pi_m\).
Its MASK marginal excess is approximately 0.00090000001. The initial sequence
joint, model calibration, temperature, and finite-step factorization all limit
claims that generated endpoints must follow the ideal \(q_s\).

## Saved evidence preserves final token occurrences

`raw_samples.csv` contains `raw_model_text` after
`tokenizer.batch_decode(..., skip_special_tokens=True)`; it does **not** contain
token IDs or preserve visible MASK markers. Both strict and repaired chemistry
operate after that tokenizer step. High strict chemical validity therefore does
not establish that every generated position contained a molecular token.

Every current UDLM [benchmark summary](../scripts/exps/denovo/benchmark.py)
separately stores `sampled_token_control_audit`, including the exact final and
input token-ID arrays (base64 little-endian uint16), the editable bitmask (msb0),
their decoded-byte hashes, and `control_token_counts.final_sampled_editable_positions`.
[Independent rescoring](../scripts/udlm/rescore_denovo_run.py) validates these
hashes/counts, immutable positions, and exact tokenizer agreement with CSV rows.
No generator change is needed to count final MASKs, rows containing MASKs, or
their association with each row's chemical outcome.

Use the decoded **editable bitmask** as the token denominator; include neither
padding nor immutable framing. The all-input MASK count is equivalent only after
the de novo `BOS MASK+ EOS PAD*` template and editable-mask equality have been
validated, as the current benchmark does. For an already independently validated
summary mapping `summary`, this CPU calculation illustrates the denominator:

```python
import base64
import numpy as np

audit = summary["sampled_token_control_audit"]
shape = (audit["rows"], audit["columns"])
ids = np.frombuffer(base64.b64decode(audit["final_sampled_ids"]["data_base64"]),
                    dtype="<u2").reshape(shape)
bits = np.frombuffer(base64.b64decode(audit["editable_mask"]["data_base64"]),
                     dtype=np.uint8)
editable = np.unpackbits(bits, bitorder="big")[:ids.size].reshape(shape).astype(bool)
final_mask = editable & (ids == audit["control_token_ids"]["mask"])
token_count = int(final_mask.sum())
token_denominator = int(editable.sum())
rows_with_mask = int(final_mask.any(axis=1).sum())
```

These are **final occurrences**, not survival trajectories. The saved input is
the original template, and intermediate corruption/reverse states are not saved.

## Reproducible three-state CPU oracle

The following reproduces the audit without loading a checkpoint, tokenizer,
dataset, or neural model. Run it from the repository with the project virtual
environment and `PYTHONPATH=src:. CUDA_VISIBLE_DEVICES=''`. State 0 represents
MASK, states 1/2 are abstract content symbols, and the clean distribution is
`(0, 0.7, 0.3)`. It uses the actual float32 time grid, but float64 bridge algebra
and an exact clean posterior. It verifies a **single-position toy** with exact
initial \(q_1\); it does not test learned models, correlated molecules, T=0.5,
or the production independent-prior initialization.

```python
from fractions import Fraction as F
import torch
from genmol.diffusion import ContinuousCategoricalDiffusion
from genmol.denoiser import denoiser_to_loo_logits

mask_mass = F(9, 10) + F(1, 10) * F(1, 5000) / 1880
pi = torch.tensor([float(mask_mass), .06, 1 - float(mask_mass) - .06],
                  dtype=torch.float64)
process = ContinuousCategoricalDiffusion(3, pi, noise_eps=.001)
clean = torch.tensor([0., .7, .3], dtype=torch.float64)
observed = torch.arange(3)[:, None]
grid = torch.linspace(1., 1e-5, 129, dtype=torch.float32).double()
distribution = .001 * clean + .999 * pi
maximum_error = 0.
for t, s in zip(grid[:-1], grid[1:]):
    alpha = 1 - .999 * t
    likelihood = alpha * torch.eye(3, dtype=torch.float64) + .999 * t * pi[:, None]
    denoiser = likelihood * clean[None, :]
    denoiser = denoiser / denoiser.sum(-1, keepdim=True)
    loo = denoiser_to_loo_logits(process, denoiser.log()[:, None, :],
                                observed, t.expand(3))
    kernel = process.posterior_probs(loo, observed, t.expand(3), s.expand(3))[:, 0, :]
    distribution = distribution @ kernel
    target = (1 - .999 * s) * clean + .999 * s * pi
    maximum_error = max(maximum_error, float((distribution - target).abs().max()))
assert maximum_error < 1e-13
print(maximum_error, float(distribution[0]))
```

Observed output on the project CPU stack:
`7.771561172376096e-16 8.990999879144849e-06`.
The tiny difference from the decimal endpoint formula includes its float32
representation. This algebra check provides no molecular quality or superiority
evidence and does not change the prospective evaluation.
